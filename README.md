# Resonance, routine anti stress

Guide sans spoiler pour Final Fantasy Resonance : routine par chapitre, points de non retour, choix de dialogue à bonus, Pots, Visions, Espers, et un constructeur de build par compagnon.

Page statique installable sur téléphone (PWA). La progression reste dans le navigateur de chaque visiteur, rien n'est envoyé nulle part.

Données de compétences extraites du jeu par la communauté (MeowDB, Game8, PowerPyx, ffresonance.wiki). Les libellés français du jeu peuvent différer.
