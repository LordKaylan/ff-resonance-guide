# Resonance, routine anti stress

Guide sans spoiler pour Final Fantasy Resonance : routine par chapitre, points de non retour, choix de dialogue à bonus, Pots, éclats de tablette, Visions, Espers, un suivi des rangs de maîtrise par compagnon et des propositions de build calculées avec le coût en PA.

Page statique installable sur téléphone (PWA). Outil personnel, gratuit, sans publicité. La progression reste dans le navigateur de chaque visiteur, rien n'est envoyé nulle part.

## Sources et crédits

- Chiffres des compétences (PA, PM, puissance de choc, seuils de maîtrise, paliers d'éveil) : [ffresonance.wiki](https://ffresonance.wiki/), merci à eux.
- Descriptions d'effets, reformulées en une ligne : MeowDB.
- Emplacements, missables, quêtes, éclats : PowerPyx, Game8, ffresonance.wiki, MeowDB, The Games Wiki.
- Conseils de build : KeenGamer, Game8, ffresonance.wiki, et nos parties.

Les libellés français du jeu peuvent différer des noms anglais utilisés ici. Si un ayant droit souhaite qu'une partie de ces données soit retirée, ouvrir une issue.
